# Sarius Palmetum Website

A responsive, GitHub Pages-ready single-page website for Sarius Palmetum in Maitama, Abuja.

## Files
- `index.html` — complete website
- `assets/garden.jpg` — garden image cropped from the supplied screenshot

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`.
6. Save. GitHub will provide your live site URL.

The site uses the venue information available from the official Sarius Palmetum website and other current listings. Prices and opening details can change, so verify them before publishing as final business information.
